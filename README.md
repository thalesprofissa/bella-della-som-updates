# Bella Della Som — atualizacoes
Este repositorio guarda apenas os INSTALADORES do player de musica das lojas.
O codigo-fonte fica em outro lugar; aqui so entram as releases geradas por
`npm run publicar` (electron-builder), e e daqui que os PCs das lojas baixam
as atualizacoes sozinhos.
Nao apague as releases antigas sem necessidade: um PC que ficou meses
desligado procura a versao dele para saber o caminho ate a mais nova.
